# Telegram AI Chatbot via n8n 

A conversational Telegram bot powered by **Anthropic Claude** using an n8n workflow pipeline.

##  The Problem
Users and teams need a quick, accessible, and automated way to interact with advanced AI models directly through messaging apps like Telegram without building a custom frontend from scratch.

##  The Outcome
A real-time, responsive Telegram chatbot that listens to user prompts, processes them via Anthropic Claude, and delivers accurate contextual answers back to the chat instantly.
