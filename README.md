# n8n-telegram-ai-chatbot

A conversational Telegram bot powered by **Anthropic Claude** using an n8n workflow pipeline.

### Business Problem

Manually responding to customer or user inquiries consumes support team time and makes response speed dependent on employee availability.

As the number of inquiries increases, this can result in:

* Delayed customer responses.
* Increased workload for support teams.
* Repetitive questions consuming employees' time.
* Limited availability outside working hours.
* Inconsistent customer communication.

### Solution

An AI-powered Telegram chatbot built with n8n automatically receives user messages, processes them through an AI model, and returns contextual responses directly in the conversation.

### Business Outcome

* Provide faster responses to customer inquiries.
* Reduce repetitive workload for support teams.
* Provide automated support around the clock.
* Improve the overall customer communication experience.
* Handle a higher volume of conversations without proportionally increasing support staff.
.
